Usuario Médico:

        Request:
            - Nome
            - Email
            - Data de Nacimento
            - CPF
            - Senha
            - Tipo
            - CRM:
                - Numero
                - Estado
            - Especialidade
        Response:
            - id (Médico)
    Login:
        Request:
            - Email ou CPF
            - Senha
        Response:
            - id (Médico)
    Buscar todos os Médicos:
        Request:
        Response:
            - id (Médico)
            - Nome
            - Especialidade
    Buscar um Médico especifico:
        Request:
            - id (Medico) (opcional)
            - crmNumero (opcional)
            - crmEstado (opcional)
            - nome (opcional, pode ser parcial)                                                                            
        Response:
            Response:
                - nome
                - email
                - crms:
                    - numero
                    - estado
                - especialidade:
                    - id
                    - nome
    Deletar Médico:
        Request:
            - id (Médico)
        Response:
            - Mensagem de confrimação
    
    Update do médico:
        Request:
            - id (Médico)
            - (Somente os dados a serem alterados)
        Response:
            - id ou os novos dados

Agendamento:
    Realizar um Agendamento:
        Request:
            - id (Usuario) # Pra saber quem criou o agendamento (coluna criadoPor)
            - id (Paciente)
            - id (Médico)
            - Data e Hora do inicio da consulta
            - Data e Hora de fim da consulta
            - Observacoes (opcional)
        Response:
            - id (Agendamento)
    
    Buscar todos agendamento por um Paciente: # Retorna todos onde o paciente aparece
        Request:
            - id (Paciente)
        Response:
            - id (Médico)
            - id (Paciente)
            - Data e hora de inicio
            - Data e hora de fim
            - Status
            - Observacoes

    Buscar todos agendamento por um Médico: # Retorna todos onde o Médico aparece
        Request:
            - id (Médico)
        Response:
            - id (Médico)
            - id (Paciente)
            - Data e hora de inicio
            - Data e hora de fim
            - Status
            - Observacoes
    
    Update do status:
        Request:
            - id (Agendamento)
            - Novo Status
            - Observacoes (opcional)
        Response:
            - id (Agendamento) (opcional)
            - (Status atualziado) (opcional)
    
    Update dos horarios caso o status seja ADIADO ou ADIANTADO:
        Request:
            - id (Agendamento)
            - Data e Hora inicio
            - Data e Hora fim
            - Observacoes (opcional)
        Response:
            - id (Agendamento) (opcional)
            - (Dados atualziado) (opcional)
